# LMS-093 — Learner Home and Assigned Courses Empty State

Epic: Learner Portal (P4)

## Acceptance criteria

- The Learner Portal presents a Dutch **Mijn cursussen** page with accessible navigation, a single main landmark, and a clear no-assignments state.
- The page uses the established LMS styling, scales to mobile, supports keyboard navigation, and shows visible focus.
- Learners can sign out from the page through the existing logout API.
- The page loads no course records. Assignment-backed access and course content are delivered in P5.
- LMS-094 verifies the page in the real browser and includes the existing administration regressions.
