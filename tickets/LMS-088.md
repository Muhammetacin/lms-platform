## CEO-reported issues

- The Lesson Type field used the Windows-native `<select>` popup, which did not match the LMS design.
- Course Preview did not provide a visible path back to its Course Builder; the browser Back button was required.

## Implementation

### UX-001 — Lesson Type

- Added a reusable select-only combobox used by both Add Lesson and Edit Lesson.
- Options come from the existing `lessonTypes` and `lessonTypeLabels` domain definitions. The API values remain `TEXT`, `VIDEO`, `PDF`, `IMAGE`, `LINK`, and `QUIZ`; the default remains `TEXT`.
- The control exposes a labelled `combobox`, `listbox`, and `option` roles with expanded, active-descendant, and selected semantics. Enter and Space open/select, arrows move the active option, Home/End jump to the ends, Escape closes without changing the value, Tab continues through the form, and outside pointer input closes the panel.
- Focus stays on the combobox during keyboard navigation and returns to it after pointer selection. Pending forms disable the control. The current value is retained in the form's named hidden input.
- The portaled list stays mounted through the pointer `click` after the trigger blurs, so the option can commit its value. Escape, Tab, and outside `pointerdown` close it; Tab keeps the browser's normal focus movement.
- The options panel is portaled to `document.body`, positioned against the trigger, and constrained to the available viewport space. It uses the LMS green focus/selection states, a clear indicator, and 44px options for touch and mouse use.
- The LMS-086 content-bearing type-change warning and its existing save/cancel logic are unchanged.
- No new dependency was added. The control is narrowly scoped to a six-option select-only field and uses a single active-descendant focus model, avoiding a larger accessibility dependency and duplicate type registry.

### UX-002 — Preview navigation

- Added `← Back to Course Builder` above the Preview header, targeting `/admin/courses/{courseId}` with `encodeURIComponent(course.id)` from the authorized Preview read model.
- The link is a normal address-based navigation and works after direct navigation in a fresh tab. `CoursePreviewUnavailable` is unchanged and exposes no Course ID or Builder link.
- The preview page's tenant and permission checks were not changed.
