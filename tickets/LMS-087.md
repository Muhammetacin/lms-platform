- Fixture SQL is parameterized. Browser flows use no Course API mocks and never navigate to or fetch the external resource URL.
- Added a separate PostgreSQL 16 Chromium `e2e` CI job with frozen install, migrations, browser installation, failure artifacts, and no changes to the existing PostgreSQL regression job.
- Added `.env.e2e.example` with placeholders only; ignored local credentials and Playwright artifacts.
- Updated the README, `docs/local-admin-smoke-test.md`, the Product Vision, and `AGENT_RULES.md` with current Course functionality and the vertical delivery gate.
