# LMS-092 — Learner Portal Access and Login Routing

Epic: Learner Portal (P4)

## Acceptance criteria

- Guests visiting the root or Learner Portal reach the existing sign-in page.
- An authenticated active MEMBER lands at `/learn`. OWNER and ADMIN land at `/admin`.
- Direct navigation to `/learn` uses the same server-side session and active default membership check. It ignores tenant IDs in the browser URL.
- A signed-in account without an active membership sees an access state and can sign out. A tenant lookup failure shows a temporary-unavailability state.
- Existing sign-in, authentication API, tenant selection, and admin authorization rules remain in effect.
- Run focused portal and authentication tests. The LMS-094 browser suite verifies the routes in the running application.
