# LMS-101 — Author API and publishing

Epic: Quiz Builder (LMS-025).

- Load and save quiz definitions through existing course-management authorization and same-organization lesson lookup.
- Validate prompts, option counts and the single correct answer. Save the full definition atomically.
- Require configured quiz questions before publication. Reject configuration writes after publication.
- Remove the quiz definition when its draft lesson changes type. Preserve it when the lesson is renamed.
