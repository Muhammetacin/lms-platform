# LMS-086 — Course Builder UI

Status: CODE COMPLETE — PR/CI BLOCKED

## Scope

Extend `/admin/courses/:courseId` with the Course Builder and publish UI over the existing Course, Module, Lesson, content, Preview, and Publishing APIs. This ticket adds no endpoint, lifecycle, schema, migration, or model.

## Implementation

- The protected Server Component authorizes using trusted tenant context and `MANAGE_COURSES` before its builder read.
- The Builder reuses the production Preview read model and Prisma store. The internal read record now includes Course timestamps, while the Preview API shape stays unchanged. Course, ordered Modules, ordered Lessons, and current content are read in one tenant-scoped `REPEATABLE READ` snapshot with a bounded set of queries and no writes.
- The existing Course management page contains Course content, Module and Lesson editors, Preview, and Publishing. LMS-085 metadata editing and Course deletion remain in place.
- DRAFT supports Module/Lesson create, metadata edit, delete confirmation, move up/down, TEXT content, HTTPS resource content, and explicit publishing confirmation. A content-bearing Lesson type change asks for confirmation on Save; Cancel restores the original type, while Confirm sends one metadata-only PATCH and leaves incompatible-content clearing to the backend.
- PUBLISHED structure and content are read-only; the UI keeps Preview, content summaries, status, and published date.
- Publish validation issues are shape-checked and mapped to local Module/Lesson titles. Unknown issue data and API error messages are not rendered.
- Same-origin request helpers emit only the existing API allowlisted fields. No tenant fields, status writes, position PATCHes, or new endpoints are used.
- URL resources are never fetched or embedded. TEXT is rendered as escaped React text.

## API contracts reused

- `GET/POST /api/organizations/courses/:courseId/modules`
- `GET/PATCH/DELETE /api/organizations/courses/:courseId/modules/:moduleId`
- `POST /api/organizations/courses/:courseId/modules/:moduleId/move`
- `GET/POST /api/organizations/courses/:courseId/modules/:moduleId/lessons`
- `GET/PATCH/DELETE /api/organizations/courses/:courseId/modules/:moduleId/lessons/:lessonId`
- `POST .../:lessonId/move`
- `PUT .../:lessonId/content`
- `POST /api/organizations/courses/:courseId/publish` with exact body `{}`
- Existing `/courses/:courseId/preview` page
