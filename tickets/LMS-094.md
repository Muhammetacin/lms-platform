# LMS-094 — Learner Portal Browser and Integration Acceptance

Epic: Learner Portal (P4)

## Acceptance criteria

- Run the complete PostgreSQL and Playwright CI jobs on the current PR commit.
- Verify guest redirects, MEMBER login and direct navigation, OWNER/ADMIN dashboard access, inactive-membership denial, and logout.
- Verify that a supplied organization ID grants no access, that a MEMBER cannot open administration or read the admin courses API, and that the learner page shows the course empty state.
- Verify the learner layout at 320px, the main landmark, and visible keyboard focus during sign-out.
- Keep the current administration, course, team, employee, and invitation regressions in the CI run.
- Record the tested commit, CI runs, review and acceptance evidence on the epic pull request.
