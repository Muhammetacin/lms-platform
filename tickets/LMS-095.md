# LMS-095 — Course Assignment Persistence

Epic: Course Assignments (P5)

- Store direct assignments against organization memberships and team assignments against teams.
- Use composite foreign keys to enforce the same organization for the course and target. Use composite primary keys to prevent duplicates and cascade when a course or target is removed.
- Deploy an additive migration with no backfill. Existing courses start with no assignments.
- Verify the migration and constraints on real PostgreSQL in LMS-099.
