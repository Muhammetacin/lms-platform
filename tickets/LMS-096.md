# LMS-096 — Course Assignment Administration API

Epic: Course Assignments (P5)

- Require the existing `ASSIGN_TRAINING` permission in the active tenant for every assignment operation.
- Expose list, candidate search, grant, and revoke on `/api/organizations/courses/[courseId]/assignments`. Candidate search returns up to 50 matching active learners or teams.
- Grant only published courses. Return a safe not-found result for foreign courses or ineligible targets. Repeated grants and revocations are idempotent.
- Use the existing trusted-origin JSON checks for mutations and private responses without caching.
