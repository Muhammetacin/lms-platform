# LMS-001 — Repository & Project Foundation

- **Status:** DONE
- **Type:** Foundation

## Goal

Create a clean, professional foundation for a production-grade multi-tenant LMS SaaS without implementing LMS functionality.

## Required stack

- Next.js with App Router
- TypeScript
- pnpm
- ESLint
- GitHub Actions
- PostgreSQL is deferred to a later ticket

## Scope

- Establish the Next.js application shell and shared layout.
- Add development, lint, typecheck, build, and production-start scripts.
- Add setup documentation, `.gitignore`, and a safe `.env.example`.
- Add CI to install dependencies and run lint, typecheck, and production build.
- Document repository working rules, product vision, and the foundation decision.

## Explicitly excluded

- Authentication
- Database setup or schemas
- Users or organizations
- Courses or quizzes
- Dashboards
- LMS APIs
- Tenant logic
- LMS-002 or later ticket work

- [x] This ticket records the scope and acceptance criteria.
