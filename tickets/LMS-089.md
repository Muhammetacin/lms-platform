# LMS-089 — Course Builder UX Redesign (MVP Interim)

Status: IMPLEMENTED — DATABASE/E2E VERIFICATION PENDING

## Objective

Refine the Course Builder Module/Lesson overview and editing workflow as a targeted interim MVP improvement. Keep the current product styling and existing API/domain contracts. The comprehensive frontend review remains a post-MVP milestone recorded in [Product Vision](../docs/00-product-vision.md); it is not part of this ticket.

## Scope and acceptance requirements

- [x] Modules show their number, title, description, lesson count, collapse control, visible Add Lesson action, and a compact accessible menu for edit, delete, and ordering.
- [x] Lessons show title, Lesson Type, configured state, compact content summary, a direct Edit content action, and a compact menu for metadata edit, delete, and ordering.
- [x] Existing ordering APIs and boundary behavior remain intact. No drag-and-drop is introduced.
- [x] Add/Edit Module and Add/Edit Lesson metadata use reusable accessible dialogs. The existing LMS-088 Lesson Type selector remains operational.
- [x] Dialogs support keyboard focus containment, initial focus, Escape/backdrop close, focus restoration, dirty-change confirmation, pending-state duplicate-submit protection, field validation, and in-place API errors.
- [x] Lesson content is read-only in the overview. Edit content opens a right-side desktop drawer and a full-screen mobile editor with the existing saved content prefilled.
- [x] Content save uses the existing API, updates the compact summary, closes on success, and emits one accessible success toast. Failure keeps the drawer and input open with an actionable inline error.
- [x] Reusable LMS-styled toasts announce successful Module, Lesson, and content mutations politely, can be dismissed, and auto-dismiss after about four seconds. Validation and destructive-operation errors remain persistent and actionable.
- [x] Dirty metadata dialogs and content drawers require an explicit Continue editing or Discard changes choice. Saving does not prompt to discard.
- [x] Module/Lesson deletion and content-bearing incompatible Lesson Type changes require accessible confirmation. Canceling a type change preserves its original type and content; confirmation sends one existing metadata update, leaving content cleanup to the backend.
- [x] Published Course structure and content remain read-only. Published Course metadata editing, Preview/Back navigation, LMS-088 interactions, API allowlists, tenant authorization, CSRF, validation, HTTPS safety, and publishing rules remain unchanged.
- [x] Focused Playwright coverage has been added for Module/Lesson dialogs, menus/order, content drawer, one toast per success, failed saves, dirty-state prompts, delete/type-change confirmation, published lock, Preview/Back, keyboard focus/Escape, and 1440px, 768px, and 375px layouts. Local execution remains pending the isolated E2E database configuration below.
- [x] No Prisma schema/migration, backend endpoint, authentication/session, authorization, tenant-boundary, or unrelated product-scope changes.
