# LMS-098 — Assigned Courses in the Learner Portal

Epic: Course Assignments (P5)

- An active learner sees each published course once if a direct assignment or a current team assignment grants access.
- List and detail reads use the same database predicate. Unassigned, draft, and foreign courses return the same not-found outcome for a learner.
- The read-only course detail reuses the existing escaped text and HTTPS resource rendering.
- Removing one grant keeps access through remaining grants. Removing the last grant, removing the learner from the last assigned team, or deactivating the learner stops access.
